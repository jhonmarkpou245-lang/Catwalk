# Catwalk Haute Couture | كاتووك للأزياء الفاخرة

متجر إلكتروني متكامل وفاخر للأزياء النسائية باللغة العربية (RTL) مبني بأحدث التقنيات مع لوحة تحكم كاملة للإدارة.

---

## 🌟 مميزات المشروع

### 1. المتجر والواجهة الأمامية (Storefront)
- 💎 **تصميم مستوحى من Haute Couture Gold**: ألوان فاخرة (الذهبي الملكي `#D4942B` والأسود الفاخر `#111111` مع خلفيات `#FAF8F5`).
- ✍️ **طباعة أنيقة**: خط `Playfair Display` للعناوين الإنجليزية وشعار الماركة، وخط `Cairo` العربي الأنيق لكل النصوص والواجهات.
- 📱 **متجاوب 100%**: دعم كامل للهواتف والشاشات اللوحية والكمبيوتر.
- 🛍️ **تجربة تسوق متكاملة**:
  - الصفحة الرئيسية مع بانرات متحركة وفئات مميزة ووصل حديثاً.
  - صفحة المنتجات مع تصفية متقدمة حسب الفئة، المقاس، اللون، ونطاق السعر.
  - صفحة تفاصيل المنتج مع معرض صور، واختيار المقاسات والألوان، وزر إضافة للسلة والمفضلة.
  - سلة مشتريات منبثقة (Drawer) وصفحة مخصصة للسلة.
  - صفحة إتمام الطلب (Checkout) متعددة الخطوات تدعم الدفع عند الاستلام أو بالبطاقات.
  - صفحة تأكيد الطلب مع كود التتبع والتفاصيل.
  - قائمة المفضلة (Wishlist) مع إمكانية النقل المباشر للسلة.

---

### 2. لوحة التحكم المخفية (Hidden Admin Panel)
- 🔒 **رابط لوحة التحكم**:
  ```text
  /admin
  ```
  أو رابط الدخول المباشر:
  ```text
  /admin/login
  ```
- 🔑 **بيانات الدخول الافتراضية**:
  - **اسم المستخدم**: `admin`
  - **كلمة المرور**: `admin123`
- 📊 **إمكانيات لوحة التحكم**:
  - **الرئيسية**: إحصائيات المبيعات، إجمالي الطلبات، عدد العملاء والمنتجات، ومخطط الأرباح.
  - **إدارة المنتجات**: إضافة، تعديل، حذف، وتحديد المخزون والأسعار والصور.
  - **إدارة الفئات**: تنظيم أقسام المتجر (فساتين، عبايات، قفاطين، إكسسوارات).
  - **إدارة الطلبات**: متابعة الطلبات، تغيير حالتها (جديد، مؤكد، جاري التجهيز، تم الشحن، تم التوصيل).
  - **قائمة العملاء**: استعراض بيانات العملاء وإجمالي مشترياتهم.
  - **كوبونات الخصم**: إنشاء وإدارة أكواد التخفيض وتحديد قيمتها وشروطها.
  - **إعدادات المتجر**: تعديل بيانات التواصل، الشحن، وشبكات التواصل.

## 🗄️ ربط قاعدة البيانات (Supabase Setup)

1. أنشئ مشروع جديد في [Supabase Dashboard](https://supabase.com/dashboard).
2. افتح **SQL Editor** في Supabase ونفّذ محتوى الملف:
   ```text
   src/lib/supabase/schema.sql
   ```
3. لإضافة بيانات تجريبية للمتجر، نفّذ محتوى الملف:
   ```text
   src/lib/supabase/seed.sql
   ```
4. انسخ بيانات المفاتيح من **Project Settings > API**:
   - `Project URL`
   - `anon public key`
   - `service_role secret key`

---

## ⚙️ متغيرات البيئة (Environment Variables)

قم بإنشاء ملف `.env.local` أو أضفها في **Vercel Settings > Environment Variables**:

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key-here
NEXT_PUBLIC_SITE_URL=https://your-domain.vercel.app
```

## 🚀 الرفع على GitHub و Vercel

### خطوة 1: الرفع على GitHub
إذا كان لديك مستودع جاهز (Repository)، نفّذ الأوامر التالية من داخل مجلد المشروع:

```bash
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git branch -M main
git push -u origin main
```

### خطوة 2: النشر على Vercel
1. سجّل الدخول إلى [Vercel](https://vercel.com).
2. اضغط **Add New > Project**.
3. اختر مستودع الـ GitHub للمشروع.
4. في خانة **Environment Variables**، أضف المتغيرات المذكورة أعلاه.
5. اضغط **Deploy**!
